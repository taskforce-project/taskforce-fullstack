Ce guide vous fait passer de zéro à un premier projet opérationnel.

## 1. Créer un compte

Rendez-vous sur [app.taskforce-project.fr](https://app.taskforce-project.fr) puis **Créer un compte**.
Trois façons de vous inscrire, qui aboutissent **toutes au même compte** (résolution par adresse e-mail) :

- **E-mail + mot de passe** — un code de vérification (OTP) vous est envoyé.
- **GitHub** ou **Google** — connexion en un clic ; votre photo de profil est reprise automatiquement.

:::tip
Vous pouvez vous inscrire par mot de passe puis, plus tard, connecter GitHub ou Google : c'est le **même
compte**, pas un doublon.
:::

## 2. L'onboarding

À la première connexion, un court parcours (non sautable) vous demande votre **rôle**, vos **compétences**
et vous laisse **nommer votre espace de travail** et **inviter votre équipe**. Ces informations
alimentent la suggestion intelligente d'affectation des tâches (Smart Assign).

## 3. Votre premier projet

Depuis le tableau de bord, créez un projet : donnez-lui un **nom libre** (deux projets peuvent porter le
même nom) et un **préfixe d'issue** court (ex. `WEB`) — il servira à numéroter vos tickets (`WEB-1`,
`WEB-2`…). Si le préfixe est déjà pris dans l'espace, il est **auto-incrémenté** (`WEB2`), jamais rejeté.
