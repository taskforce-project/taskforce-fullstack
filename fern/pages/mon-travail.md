**Ma file** rassemble **votre** travail à vous, agrégé depuis **toutes les opérations** où vous
intervenez. Plus besoin d'ouvrir chaque projet : ce qui vous incombe est réuni au même endroit.

{/* SCREENSHOT: ma-file — la vue « Ma file » avec la colonne Assignment (Accept / Decline) */}

## Les vues

| Vue | Ce qu'elle regroupe |
| --- | --- |
| **Toutes mes files** | Une vue d'ensemble de tout ce qui vous concerne. |
| **Tâches** | Les tâches dont vous êtes responsable, tous projets confondus. |
| **Sprints** | Les sprints des opérations où vous travaillez. |
| **Pages** | Les documents récents de vos opérations. |

## Accepter ou refuser une assignation

Quand une tâche vous est **attribuée par quelqu'un d'autre**, elle arrive ici avec la mention
**« À valider »** et deux boutons : **Accepter** ou **Refuser**. C'est votre file — vous gardez la
main sur ce que vous prenez en charge.

Le fonctionnement complet (ce qui se passe à l'acceptation, au refus, et côté personne qui a assigné)
est détaillé dans son guide dédié. → [Accepter ou refuser une assignation](/guides/assignations)

<Tip>
  Une tâche que **vous** vous assignez à vous-même est **acceptée d'office** : pas de validation à
  faire, elle est directement à vous.
</Tip>
