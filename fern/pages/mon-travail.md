**Ma file** rassemble **votre** travail à vous, agrégé depuis **toutes les opérations** où vous
intervenez. C'est la réponse à *« qu'est-ce que j'ai à faire, moi, aujourd'hui ? »* : plus besoin
d'ouvrir chaque projet un par un pour reconstituer votre charge — tout ce qui vous incombe est réuni
au même endroit.

{/* SCREENSHOT: ma-file — la vue « Ma file » avec la colonne Assignment (Accept / Decline) */}

## Les vues

Ma file se décline en quatre vues, selon ce que vous voulez voir :

| Vue | Ce qu'elle regroupe |
| --- | --- |
| **Toutes mes files** | Une vue d'ensemble de tout ce qui vous concerne. |
| **Tâches** | Les tâches dont vous êtes responsable, toutes opérations confondues. |
| **Sprints** | Les sprints des opérations où vous travaillez. |
| **Pages** | Les documents récents de vos opérations. |

Chaque vue **traverse les opérations** : là où un tableau de projet ne montre qu'un projet, Ma file
recompose *votre* périmètre à travers tous.

## Accepter ou refuser une assignation

Quand une tâche vous est **attribuée par quelqu'un d'autre**, elle arrive ici avec la mention
**« À valider »** et deux boutons : **Accepter** ou **Refuser**. C'est votre file — vous gardez la
main sur ce que vous prenez en charge, plutôt que de vous retrouver responsable sans le savoir.

- **Accepter** confirme la prise en charge : la tâche est officiellement à vous.
- **Refuser** la libère et **prévient la personne** qui vous l'avait confiée.

Le fonctionnement complet (côté vous, côté personne qui assigne) est détaillé dans son guide dédié.
→ [Accepter ou refuser une assignation](/guides/assignations)

<Tip>
  Une tâche que **vous** vous assignez à vous-même est **acceptée d'office** : pas de « À valider »,
  elle est directement dans votre file. La validation ne concerne que ce que les **autres** vous
  confient.
</Tip>
