Le **Dashboard** est le premier écran de votre espace : votre poste de commandement. Il a deux
fonctions — vous **remettre dans le contexte** (« reprenez où vous en étiez ») et donner l'**état de
vos opérations** d'un coup d'œil, sans ouvrir chaque projet.

## En haut

- Un **accueil personnalisé** (le moment de la journée, votre nom) et un accès direct pour
  **reprendre** votre travail en cours.
- Une **recherche** — opération, tâche, action — la même que la palette `Ctrl + K`.
- Un raccourci pour **connecter vos outils** (GitHub, Slack…) à l'espace.
  → [Intégrations](/guides/integrations)

## Les cartes

Le tableau de bord est composé de **cartes** qui synthétisent l'activité. Selon votre espace, on y
trouve notamment :

| Carte | Ce qu'elle montre |
| --- | --- |
| **Santé des opérations** | L'état global de vos projets actifs. |
| **Tâches ouvertes** | Le volume de travail en cours. |
| **À traiter** *(needs attention)* | Ce qui réclame votre attention en priorité. |
| **Débit** *(throughput)* | Le nombre de tâches terminées dans le temps. |
| **Vélocité** | Le rythme de livraison, et sa tendance. |
| **Burndown** | La trajectoire d'un sprint vers son terme. |
| **Tâches résolues** | Ce qui a été bouclé sur la période. |
| **Charge d'équipe** | La répartition du travail entre les personnes. |
| **Usage Cortex** | Votre consommation d'IA. → [Vue d'ensemble de l'IA](/guides/ia-vue-ensemble) |
| **Graphe IA** | Un graphe généré par Cortex à partir de vos données. |

Plusieurs cartes offrent un **sélecteur de période** (**24 h**, **7 jours**, **30 jours**) : vous
ajustez la fenêtre d'analyse selon que vous regardez la journée ou le mois.

## Dashboard, Intelligence : lequel quand ?

Le Dashboard est pensé pour le **coup d'œil quotidien** — l'essentiel, tout de suite. Pour creuser
(temps de résolution, tendances, charge détaillée, graphes à la demande), passez à la vue
**Intelligence**. → [Analytics](/guides/analytics)

<Tip>
  Le Dashboard est aussi un **point de départ** : depuis lui, on crée une opération, on saute à une
  tâche via la recherche, on ouvre l'assistant. C'est l'écran où l'on **repart**, pas seulement celui
  où l'on **regarde**.
</Tip>
